Overview
A web service to manage the user's trip log.
사용자가 자신의 여행기를 자유롭게 관리할 수 있는 웹 서비스.
Tech stack
Java, Spring Boot, MySQL, Vue.js
Contributions
  • Designed database structure and wrote SQL queries and developed back-end APIs following the MVVM pattern.
  • Designed and implemented a back-end CRUD API for finding locations and planning trips, as well as related UI/UX design and frontend development.
  • Developed a feature to create markers and calculate distances using KakaoMap API in Vue.js, and fetched real-time weather data from the Korea Meteorological Administration API using Spring Boot.
  • Developed the frontend for a community feature, enabling flexible file uploads and cancellation during post creation and editing.
  • 데이터베이스 설계, SQL 쿼리 작성 및 백엔드 API, 프론트엔드 페이지를 MVVM 패턴에 맞춰 개발
  • 장소 찾기 및 여행 계획과 장소에 관련된 백엔드 CRUD API 설계 및 구현, UI/UX 디자인 및 프론트엔드 구현
  • Vue.js에서 카카오맵 API로 마커 생성 및 거리 계산, Spring Boot에서 기상청 API로 실시간 날씨를 불러옴
  • 커뮤니티 기능의 프론트엔드를 담당, 게시글 생성과 수정 시 자유로운 파일 업로드 및 취소 가능
