Overview

Voting platform for middle and high school.

중·고등학교 학생 임원 투표 서비스

Tech stack
Java, Spring Boot
  • Selected Spring Boot for its excellent load handling by efficiently processing real-time data like streaming and chat.
  • 스트리밍, 채팅 등 실시간 정보를 많이 처리해서 부하를 잘 버티기 좋은 Spring Boot 선택
MySQL
  • Project-related data is stored in MySQL, while chat data is stored in Redis.
  • 프로젝트와 관련된 데이터는 MySQL에, 채팅 데이터는 redis에 저장 중.
RTMP/HLS, FFmpeg
  • Browser socket for the broadcast feed → converted to RTMP using FFmpeg → processed by the RTMP/HLS server → delivered to the browser as HLS.
  • 브라우저로부터 방송 화면에 대한 소켓이 도착 -> FFmpeg로 RTMP 변환 -> RTMP/HLS 서버 -> 브라우저 HLS 수신
Nginx, Docker, Jenkins, AWS
  • Infrastructure-related tech stack:
  • Nginx: Manages the web server and RTMP protocol.
  • Docker: Containerizes services.
  • Jenkins: Used for CI/CD; set up with GitLab integration.
  • AWS: Used for deployment.
  • 인프라 관련 기술 스택
  • Nginx: 웹서버 및 rtmp 프로토콜 관리
  • Docker: 서비스 컨테이너화
  • Jenkins: CI/CD를 위해 사용, 프로젝트가 GitLab을 사용하여 Jenkins를 이용해 CI/CD 구축.
  • AWS: 배포
Git, GitLab, Jira
Contributions
  • Implemented real-time streaming using the FFmpeg library in RTMP, HLS, and Spring Boot.
  • Adjusted FFmpeg parameters and Nginx settings to reduce RTMP streaming latency from 20–30 seconds to under 10 seconds.
  • Set up project infrastructure and managed the system.
  • RTMP, HLS, Spring Boot에서 FFmpeg 라이브러리를 이용한 실시간 스트리밍 구현
  • RTMP 스트리밍이 20~30초의 지연에서 10초 미만의 지연 시간을 갖도록 FFmpeg의 파라미터 및 Nginx의 설정 조정
  • 프로젝트 인프라 셋업 및 시스템 관리
